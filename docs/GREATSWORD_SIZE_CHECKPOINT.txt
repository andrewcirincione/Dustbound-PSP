Dust 1.0.6 — COMPLETED AND PUBLISHED

User requested a modest reduction to oversized greatswords.
Twenty longer expansion greatswords use .86 longitudinal blade size and .94
blade width beyond the fixed grip zone: approximately 10–12% less overall length.
Compact indices 100 (Breaker-Yard Slab), 101 (Fen Bastard Sword), and 103
(Quarry Splitter) retain their original size. Both palm positions, the raised
shoulder-rest angle and blade/leading-arm depth remain aligned.
Combat stats, item IDs, other weapon families, smith stock and save format 32
are unchanged.

Validation completed:
- All 47 native regression suites passed locally and in GitHub Actions.
- 260 production-renderer review frames generated; long Zweihander and legendary
  shoulder-rest views checked in both facings.
- Four representative greatswords tested in both facings in actual PPSSPP 1.20.4,
  including eight equipment/combat cases and smith weapon/armor previews.
- Local PSP run passed idle, combat, both facings and both smith preview types.
- Actual PSP inventory captures visually compared against 1.0.5.
- Public release hashes match qualifying workflow package hashes; public EBOOT
  matches the locally built/emulated binary. No physical PSP hardware test.

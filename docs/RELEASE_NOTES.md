# Dustbound 0.6.2 — analog movement and D-pad menus

- Analog stick is the only character movement control, both outdoors and indoors.
- D-pad Up toggles a live status panel: six body-part health bars, blood, food, fatigue, load/capacity and bleeding. It tracks the selected survivor and stays hidden by default. Press Up again to hide it. Time continues; R still toggles tactical pause.
- D-pad Down opens Skills, Left opens worn equipment, and Right opens squad orders.
- Menus retain D-pad navigation. Triangle, Start, Select and shoulder-button shortcuts are retained.
- D-pad presses no longer interrupt jobs or cancel group travel. Opening menus pauses the simulation without discarding destinations.
- Desktop development controls use WASD for the analog stick and arrows for the D-pad.

## Install

Extract the PSP folder from Dustbound-0.6.2-PSP.zip to the memory-stick root, or replace PSP/GAME/DUSTBOUND/EBOOT.PBP. Keep existing saves; the save format is unchanged.

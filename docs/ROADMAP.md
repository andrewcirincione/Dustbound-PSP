# Dustbound development progress

## 0.4.0: playability and coherent artwork

- [x] Clear target/action prompts and close interaction reach.
- [x] Specialist NPC services rather than universal menus.
- [x] Worn/candidate equipment comparison in pack and market.
- [x] Fourfold town spacing, compact streets, wilderness hostiles, local/world atlas.
- [x] Painted modular characters, beasts and frontier props, projected building shadows, textured rooms.
- [x] Save-coordinate migration with explored terrain preserved.

- [x] Starting-loadout balance and stolen-item transfer correction.
- [x] Regression tests and native visual-review iterations.

The unreleased 0.3 graphics/interior candidate is included in this milestone. Older released builds and their evidence remain in git history.

## 0.5.0 completed / next design priority

Completed: four heavy weapon families, strength/arm handling, faction/profession equipment and advice, regional markets, timed independent guards, medic/merchant separation, v5 save migration and the [whole-game review](DESIGN_REVIEW_V050.md).

Next priority: one authored salvage-route/rescue/raider-leader loop whose outcomes persist in town stock, NPC dialogue, road safety and retaliation. Then deepen defeat/recovery, outpost job logistics and independent squads. Require physical PSP-3000 frame-time and save qualification before claiming hardware readiness.

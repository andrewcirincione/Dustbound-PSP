# Development ledger

## 0.2.0 — frontier expansion

Implemented and covered by native and/or EBOOT playtests:

- [x] Grittier western–samurai character and building art.
- [x] 384 × 384 world, 16 settlements, 9 biomes, rivers/fords, atlas, weather.
- [x] Character creation and appearance editing.
- [x] 2,016 modular equipment variants, six visible slots, catalog render audit.
- [x] Timed attacks, hit stop, stagger, recoil, directional weapon animation, sound effects.
- [x] Limb health, bleeding, knockout, death, limb loss, rescue and prosthetics.
- [x] Eight-member squads, 20 use-based skills, 8 jobs.
- [x] Trade, finite stock, daily catalog rotation, reputation/prosperity pricing.
- [x] Theft ownership, fencing, lockpicking, bounty, custody, bail and escape.
- [x] NPC service dialogue and ambient speech.
- [x] Contracts, journal, factions, prosperity and ownership events.
- [x] Construction, storage, farming, recipes, custom forging, research.
- [x] Six manual saves, autosave, checksum validation, backups, v0.1 migration.
- [x] Eighteen contextual in-game guide chapters.

## Remaining release qualification and depth

- [ ] Test on physical PSP-1000/2000/3000/Go; measure frame time, memory, audio and battery behavior.
- [ ] Qualify suspend/resume, low battery, full memory stick and interrupted writes on hardware.
- [ ] Larger authored settlement layouts, interiors and more varied resident dialogue.
- [ ] Long-range hierarchical navigation and more sophisticated group formations.
- [ ] Rich faction diplomacy, physical siege campaigns and consequences beyond town event simulation.
- [ ] Multi-squad management, more industrial production chains and storage routing.
- [ ] More hand-authored combat stances, creature families and narrative encounters.
- [ ] Extensive long campaign balance and accessibility testing.
- [ ] Slavery/prison economy, disguise system and other unimplemented Kenshi-scale systems.

0.2 is a playable original alpha, not a claim that every mechanic in Kenshi has been recreated. Completed systems above vary in depth; the guide describes their actual rules. Future work is tracked here and in repository issues. No unattended future development or scheduled screenshot posting is implied.

## 0.1.0 baseline

Five towns in a 128 × 128 world, four-member squad, body-part combat, skills, trade, looting, camps, research and saves. Released with 61 passing simulation checks and EBOOT emulator captures. 0.2 retains save migration for this version.
